# ContentFlow CMS

A React + Vite Content Management System frontend demo.

## Requirements
- Node.js (LTS)
- npm

## Run in VS Code
1. Extract the ZIP and open the `contentflow-cms-react` folder in VS Code.
2. Open Terminal in that folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed in the terminal (usually http://localhost:5173).
5. Create an account using Sign Up, then log in.

## Features
- Login and sign-up demo
- Dashboard and content summary cards
- Content list with thumbnail images, search, status filters, add, edit and delete
- Templates, analytics, settings and profile pages
- LocalStorage persistence

This is a frontend demonstration. Authentication and LocalStorage are not suitable for production security. Thumbnail images load from the internet, so an internet connection is needed to display them.
